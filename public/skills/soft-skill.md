# Soft Skill
**Author:** Leonxlnx
**Domain:** Craft & Taste
**Purpose:** High-end visual design guidance for premium typography, spacing, depth, and animation systems.

## What It Does
Addresses the soft qualities of interface design — the typographic rhythm, spatial relationships, layering, and motion that create a premium feel. Bridges the gap between technically correct and visually distinguished.

## Input Requirements
- Design or component to refine
- Current typography and spacing system
- Visual direction or reference aesthetic

## Output
- Typography refinement recommendations
- Spacing and rhythm improvements
- Depth and layering guidance
- Animation system recommendations

## Quality Criteria
Typography must have a clear hierarchy with at most 3 distinct scales. Spacing must follow a consistent scale. Depth must be earned — not decorative. Motion must feel inevitable, not added.

## Edge Cases
- Designs with too many type sizes competing for hierarchy
- Spacing that looks right in isolation but breaks in flow
- Depth effects (shadows, blur) that don't match the light model
- Animation systems that are inconsistent across components
- Premium aesthetic on low-information-density screens

## Best Practices
- Start with typography — it carries more visual weight than color
- Use a 4pt or 8pt spatial scale and never deviate
- Shadows should have a consistent light source direction
- Motion system should be defined once and applied everywhere
- Less depth = more premium in most contexts
